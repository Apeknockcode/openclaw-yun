## ✍️ 写作风格规范

### 标题公式（奇特吸引人，两版交替）

**钩子版**（A 类主用）：
```
【反常识结论/悬念提问】+ 【让人想点开的钩子】
例：为什么便利店永远开在路口？背后是 3 个精算过的生意逻辑
```

**价值版**（B 类主用）：
```
【一个具体的小生意/副业】+ 【普通人怎么上手（合规表述）】
例：宠物殡葬这门生意，一个人就能做，启动成本不到 2 万
```

标题注意：不写夸张标题党（「震惊！」「速看！马上删」等），靠真实的反常识钩子吸引点击。

### 文章结构模板（5段式）

```
① 钩子开场  ~150-200字
   → 反常识结论/问题直接砸出来，第一句就让人「咦？」
   → 例："你知道吗？你每天逛的便利店，选址根本不是看人流量——"

② 展开正文  ~800-1200字（3-5个小节）
   → 每个小节一个小钩子：讲清「为什么」「怎么运作」
   → A类：层层揭秘，结尾留反转/彩蛋
   → B类：讲透模式 → 给落地路径 → 提醒风险

③ 创业思路落地（B 类专属）  ~200字
   → 给「普通人怎么试」的具体步骤（启动成本/第一步/验证方法）
   → 必须有风险提示：不是人人都能成

④ 互动钩子  ~100字
   → 具体提问引导评论："你见过最离谱的小生意是什么？评论区聊聊👇"

⑤ 关注引导  ~50字
   → 自然引导：想看好玩的生意脑洞，关注「启源符号」奇思妙想栏目
```

### 文风要求
- **开口即钩子** — 第一句给反常识结论/悬念，不做铺垫
- **讲故事、讲人话** — 不写教科书语言，多用「你」「我」对话感
- **有细节、有数字** — 具体到启动成本、单价、毛利（有据可查的数字）
- **不劝退不画饼** — 创业类必须平衡：给希望也讲风险
- **字数**：每篇 1000-1800 字（公众号阅读习惯，别太长）

## ⚠️ 合规红线（本技能专属，不同于启源符号主技能）

1. **不夸大收益**（广告法）— 禁止「月入十万」「躺赚」「稳赚不赔」；写收益必须用「真实案例 + 个体差异 + 仅供参考」的表述
2. **创业思路必须带风险提示** — 每篇 B 类文末必须有「风险与提醒」小节：市场验证、启动成本、失败可能
3. **不碰灰产/黑产** — 刷单、赌博、灰产引流、违法边缘项目一律不写
4. **不制造焦虑** — 不写「再不创业就晚了」「被时代抛弃」类恐吓文案
5. **数据有据** — 案例、数字、商业模式描述必须真实可查，不编造品牌/项目（真实品牌需用公开信息）
6. **不贬低同行/竞品** — 拆解商业模式时不指名道姓攻击
7. **不做投资/理财建议** — 涉及投资类话题只做科普，不给具体投资建议
8. **与本公众号主栏目隔离** — 奇思妙想文章不出现通信/宽带/号卡内容，也不出现 fenxiaohao.com 推广（避免两个栏目内容互相污染）

## 🔄 写作与发布流程

1. **选题** — 从池 A/池 B 选择，按 6:4 或 5:5 轮换；选题先过本技能合规红线
2. **查证** — 奇特主题需查证事实（web_search 验证冷知识/数据/商业模式真实性）；创业案例查公开信息
3. **写作** — 按 5 段式模板 + 文风要求写 Markdown 源稿
4. **配图** — 生成信息图或采集真实图片，上传微信 CDN（需 access_token）
5. **封面** — Pillow 生成独立配色封面（900x383），上传微信素材库拿 media_id
6. **排版** — 生成微信兼容 HTML（table 布局），标题/摘要含核心关键词
7. **发布** — draft_only 模式上传草稿箱（API 方式与主技能相同：urllib.request + ensure_ascii=False 防乱码），access_token 用启源符号的 AppID/Secret 获取
8. **记录** — 在 memory/ 当日文件追加发布记录（栏目/类型/标题/状态/media_id），不得覆盖已有内容

### API 上传（防乱码，同主技能技术）
```python
json_bytes = json.dumps(article, ensure_ascii=False).encode('utf-8')
req = urllib.request.Request(url, data=json_bytes, method='POST')
req.add_header("Content-Type", "application/json; charset=utf-8")
```

### 输出文件（独立命名，与主技能文件区分）
1. `qsmx_draft_YYYYMMDD.md` — Markdown 源稿
2. `qsmx_html_YYYYMMDD.html` — 微信兼容 HTML
3. `qsmx_cover_v{N}.jpg` — 独立封面
4. `cdn_urls_YYYYMMDD.json` — CDN URL 记录
