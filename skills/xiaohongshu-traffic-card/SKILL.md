## 1. 平台双引擎逻辑（一切方法的地基）

小红书的本质是**生活方式搜索引擎 + 种草社区**：

1. **推荐引擎**：新笔记先进小流量池，按互动率（点赞/收藏/评论/关注/停留）决定是否推入更大池子，逐级赛马
2. **搜索引擎**：用户搜"流量卡推荐""流量卡怎么选"，笔记靠**标题与正文的关键词覆盖**排序。搜索流量转化意图强，是种草变现的主力

**结论**：标题为搜索写，封面为推荐写——标题埋用户会搜的词，封面抢信息流里的 0.5 秒注意力

## 2. 养号期核心策略（0-20篇）

### 节奏控制
- **频率**：每天 1 篇，不要一天 2 篇。新号一天内发多篇同主题内容容易触发双重审核
- **时间**：晚上 8-10 点发（流量卡目标人群下班刷手机高峰）
- **预期管理**：

| 篇数 | 小眼睛 | 对策 |
|------|--------|------|
| 前 5 篇 | 0-200 | 正常，坚持发 |
| 第 5-7 篇 | < 200 | 考虑换封面/标题方向 |
| 第 10 篇后 | 仍低 | 考虑换号 |

### 内容角度选择

| 角度类型 | 营销感 | 适合阶段 |
|----------|--------|---------|
| 个人踩坑故事 | ⭐ | 养号期首选 |
| 对比测评 | ⭐⭐ | 养号期 |
| 干货科普 | ⭐ | 养号期 |
| 价格冲击 | ⭐⭐⭐ | 养号中后期 |
| 直接推销 | ⭐⭐⭐⭐⭐ | 不推荐新号用 |

> **养号期前 10 篇一律用个人踩坑故事和干货科普**

### 内置脚本与养号阶段的对应

| 脚本 | 内容角度 | 养号阶段 |
|------|---------|---------|
| `generate_xhs_images_v2.py` | 避坑指南（踩坑故事+知识科普） | 养号期前 10 篇 ✅ |
| `generate_xhs_how_to_choose.py` | 选卡指南（干货科普） | 养号期前 10 篇 ✅ |
| `generate_xhs_images.py` | 套餐推荐对比 | 养号后/引流期 |

## 3. 笔记创作方法

### 3.1 标题（20 字内，必埋搜索词）

**公式**：人群/场景 + 关键词 + 结果/情绪

流量卡垂类搜索词优先级：
1. **核心词**：流量卡、电话卡、手机卡
2. **场景词**：学生党、租房、出差、备用卡、副卡
3. **价格词**：19元、29元、月租低、大流量
4. **问题词**：坑、套路、避坑、靠谱吗

**自查**：把自己当用户，这个标题里有没有你会在搜索框里打的词？

**示例**：
- ✅ 「学生党|流量卡|月租19到底够不够用」
- ✅ 「办了3张流量卡之后|才知道的避坑指南」
- ❌ 「绝了！这个流量卡太香了」（无搜索词）

**不要标题党**：小红书用户对"惊了""绝了"已免疫，具体数字和场景比感叹词有效。

### 3.2 封面（信息流里的 0.5 秒）

三种可靠形态：
1. **对比图**：前后套餐价格对比
2. **清单图**：大字号列要点
3. **场景实拍+大字标题**：签收快递、插卡使用

- 图上文字 ≤ 12 字，手机缩略图下要能看清
- 首图决定点击，2-9 图承载内容——教程类把步骤拆进图里，用户为"收藏价值"点收藏

### 3.3 正文结构

```
钩子（前两行，折叠线之上）：痛点场景 or 结果前置
↓
个人经历锚点（为什么信我：具体价格/时长/失败经历）
↓
干货主体（清单化，每点一行小标题+两三句展开）
↓
方法论（选卡步骤 / 操作指南）
↓
行动引导（评论区互动 / 收藏理由）
```

**真实锚点是关键**：具体价格、流量数、使用时长，不要编。

### 3.4 Emoji 分段规范

- 每大段开头 1 个做视觉锚点
- 推荐：📱 💰 ✅ ❌ ⚠️ 💡 🎯 📋 👇
- 不堆砌，一个够用

### 3.5 标签策略（5-10 个，三层覆盖）

| 层级 | 类型 | 示例 | 数量 |
|------|------|------|------|
| 大流量词 | 核心类目 | #流量卡 #手机套餐 #话费 | 2-3 个 |
| 精准词 | 场景/人群 | #学生党流量卡 #低月租流量卡 | 2-3 个 |
| 长尾词 | 搜索突围 | #月租19元流量卡 #流量卡避坑 | 2-3 个 |

> **长尾词是搜索排名突破口**，一定要加。

## 4. 配图生成

使用 SVG + cairosvg 渲染（解决 PIL 渲染中文字体间距问题）。

### 前置条件

```bash
# Python 依赖
pip install cairosvg Pillow fonttools

# Linux 中文字体
dnf install google-noto-cjk-fonts    # Fedora/RHEL
apt install fonts-noto-cjk           # Debian/Ubuntu
```

### 运行脚本

```bash
# 选卡指南（3步法）— 养号期推荐
python3 scripts/generate_xhs_how_to_choose.py

# 避坑指南 — 养号期推荐
python3 scripts/generate_xhs_images_v2.py

# 套餐推荐对比 — 养号后/引流期
python3 scripts/generate_xhs_images.py
```

输出到 `assets/xiaohongshu/YYYY-MM-DD-主题/` 目录，共 6 张。

### 配图风格规范

- 尺寸：1080×1440（3:4 竖屏）
- 小红书暖色调（粉/珊瑚/暖橙/紫）
- 圆角卡片 + 轻阴影
- 宽松字间距行间距
- 无 emoji 纯文字排版

## 5. 数据诊断

| 症状 | 问题环节 | 对策 |
|------|----------|------|
| 曝光低（小眼睛少） | 没进流量池 | 检查标题搜索词；养号期耐心 |
| 曝光高点击低 | 封面/标题不行 | 换封面重发 |
| 点击高互动低 | 正文无价值 | 加真实锚点、清单化重构 |
| 赞多收藏少 | 留存价值不足 | 往"可执行清单"方向改 |
| 收藏多不涨粉 | 账号无预期 | 做系列选题 |

## 6. 合规红线 & 违禁词自查

### 号卡类特别注意

- ❌ 绝对化用语：最低价、最便宜、第一品牌 → ✅ 月租低至、性价比高、口碑好
- ❌ 虚假宣传：无限流量、不限速 → ✅ 大流量套餐、百G级别
- ❌ 站外引流：留微信号/二维码 → ✅ 引导评论区留言
- ❌ 金融擦边：不碰"投资""理财""返利"等词
- 发布前用小红书自带内容体检自查

### 违禁词自查清单

| ❌ 禁用 | ✅ 替换 |
|---------|---------|
| 最便宜、全网最低、第一品牌 | 性价比高、口碑好 |
| 免费送、限时抢购 | 免费申请、优惠活动 |
| 百分百、绝对、保证 | 通常、一般、大多数 |
| 微信号、手机号、加V | 评论区留言 |

- [ ] 标题控制在 20 字以内，埋了搜索词

- [ ] 封面图文字 ≤ 12 字
- [ ] 发布时间选在 20:00-22:00
