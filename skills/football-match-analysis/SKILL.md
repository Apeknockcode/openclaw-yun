## 何时使用
- 分析具体比赛：联赛（单回合）、杯赛（两回合）赛前分析
- 预测比分、判断大小球方向
- **预测总进球数（竞彩"总进球"玩法）**
- 制定竞彩/串关策略、防冷方案
- 临场校验（首发公布后）

## 分析前置：收集数据
开始分析前先收集以下数据；用户未提供时标注"数据缺失，保守处理"：
1. 两队排名（计算排名差）
2. 伤停名单（按位置关键度分级，**必须核对官方伤停/首发来源**）
3. 上一场赛果与过程（判断尊严惨败）
4. 周中赛程（杯赛/120分钟加时/一周双赛/欧战夹击）
5. 历史交锋近10次胜率
6. 支持率 vs 赔率隐含概率（热度偏差）
7. 主客场战绩（识别"不败假象"）
8. 场均进球/失球（判断烂防等级与进攻火力，**近10场与近6场口径都看**，进球数定档基线用近6场；**"进攻荒/状态差"类数据必须核对最近1-2轮是否已破（V3.9 规则26）**）
9. **赛前深度文**：搜狐/腾讯/网易体育等中文源"XX vs XX 比赛分析"——常含官方伤停名单与"剧本信号"，是验证单源信息的关键
10. **海外预测模型**：theyscored、footystats、apostaganha、zerozero——交叉验证方向，排名接近（≤3位）时必查
11. **批次预检（V3.22 规则52）**：扫当日赛程定基调——首轮/早轮场次数、近5天场均进球（是否大球季）、警示局数量、数据源可用性；基调矛盾时（如大球日判小）【风险】栏写明理由
12. **数据源降级路径（V3.22，8/16 实操固化）**：web_search（Perplexity 402 额度耗尽）不可用时备用源——okooo（赛程/盘口全量实测）、500.com shuju/yazhi 页（近况/实时亚盘，免费）、zgzcw 99家欧亚、sogou/360 搜索（H2H 补充）——预测前先确认哪些源可用，不可用则按规则39/40 降信心/标跳过
13. **源清单固化（V3.50）**：①**官方竞彩 API `webapi.sporttery.cn` getMatchCalculatorV1**（HAD/HHAD/TTG/CRS 全赔率含总进球；**2026-09-20 实测：须带 `Referer: https://www.sporttery.cn/`；`getMatchListV1.qry` 返「禁止访问」不可用；API 只返回当前在售场次**）②**titan007**：`bf.titan007.com/football/Next_YYYYMMDD.htm`（赛程+sId）→ `zq.titan007.com/analysis/{sId}cn.htm`（**须带 Referer: bf.titan007.com**；含伤停/上轮首发/天气/大小球初盘/盘路）③okooo：竞彩页+/jingcai/shuju/pankou/（亚盘 15 家）+history 页（**须 gb18030 解码**）④雷速/腾讯/直播吧/懂球帝不可用

## 分析流程：7步法
- **第1步 尊严惨败**：输低级别球队/死敌/最后10分钟绝杀/德比惨败 → 触发红线15，进球预期+1球（德比惨败+1.5球），大小球看大；同时有≥2名在阵进攻核心 → 叠加×1.5。
- **第2步 体能消耗**：120分钟加时 → 触发红线16，防守稳定性-25%（按排名差距打折），大小球自动看大+0.5球；周中杯赛 -15%/-10%；连续3周一周双赛 -30%/-15%；**欧战资格赛夹击+主帅亲承赛程密 → 按周中杯赛级处理（防守-15%起，可能轮换留力）**。
- **第3步 基本面交叉验证**：实力差距是否匹配排名？有无伤停/疲劳/战意重大变量？是否为杯赛跨级别首回合（红线13：优先1球小胜或平局）？**是否为杯赛次回合+主队首回合落后（V3.6：战意驱动优先，规则15）？** **V3.7：是否为联赛首轮/揭幕战？——是则按正常判定，不预设保守（规则19）；状态数据与传闻是否分清（规则18）？** **V3.8：是否深盘警示局（竞彩-1 vs 亚盘 0.25~0.5）→ 主推让平/让负双选/压档分型（规则22）？是否有平局高频信号（多源提示/客队客场平局率≥35%/双方状态均差）→ 平局格进主推（规则24）？** **V3.9：是否退盘/降盘+深盘警示 → 禁止切不让球胜（规则25）？状态差/进攻荒数据是否已核对最近1-2轮（规则26）？** **V3.10：是否真深盘（亚盘≥竞彩）→ 主推让平/让负双选、让胜窄格不单押（规则27）？是否亚盘≤0（平手/受让）→ 势均力敌不压档（规则28）？是否-2深盘 → 受让方+2不败视角（规则29）？** **V3.11：主推玩法定让球还是不让球——不让球主推三场景（强弱分明无盘口反向+赢球数判不清 / 势均力敌非互爆 / 规则25无反向信号）是否命中（规则30）？** **V3.15：是否为次回合局？落后方主场晋级线（需赢2球直接晋级+实力差支撑→让胜候选）？是否"让平锚定"（规则34）？**
- **第4步 热度偏差**：支持率 vs 赔率隐含概率偏差>15% → 重新评估；>20% → 反向思考或双选覆盖（红线1）。**升盘+共识≥80% → 过热反向，方向不得单选（V3.6 规则16）。**
- **第5步 虚实判断**：实热（有基本面支撑）vs 虚热（只有名气）。结合战意系数（红线3：保级主场+30%；杯赛次回合首回合领先≥3球方-30%、落后方+30%；无欲无求 vs 必须抢分 → 抢分方+20%；一周双赛 → 防守-25%、进攻-10%）。
- **第6步 烂防豁免**：对手场均失球>2.0（🔴历史级烂防）→ 触发红线17，本方"进攻残阵"扣减降权50%，仍可预期本方进球≥1.5；1.6~2.0（🟡）→ 降权25%；客场连续10场以上丢球 / 防线核心+门将同时缺阵 → 烂防等级自动升1级。**近10场场均失球与近6场口径不一致时取更高等级**。**本方状态红线检查（V3.4）：季前热身≥2连败 / 慢热 / 锋无力 → 触发结构崩盘规则降级条件（规则6补丁）。**
