# 23条红线详解（框架 V3.1）+ V3.15~V3.55 增量红线 24-157

## 红线1：热度异常必须量化验证
支持率与赔率隐含概率偏差 >15% → 该方向必须重新评估；>20% → 必须反向思考或双选覆盖。

案例：216场维京客胜（支持率88% vs 隐含60%，偏差28% → 打出冷门）；212场马尔默主胜（79% vs 55%，偏差24%，4主力停赛 → 打出冷门）。

## 红线2：主力伤停 > 排名/名气（伤停分级制）
伤停按"位置关键度"分级，而非人数：

| 等级 | 定义 | 案例 |
| :--- | :--- | :--- |
| 🔴重度 | 同位置多人缺阵或核心位置（锋线支点/后防领袖/一门）缺阵 | 米拉索尔一门+二门全缺 = 重度 |
| 🟡中度 | 1-2名主力缺阵，但有合格替补 | 巴西国际主力后腰缺阵 = 中度 |
| 🟢轻度 | 轮换/替补伤缺，主力框架完整 | 里莫轮换前锋缺阵 = 轻度 |

**组织核心分类**：
- **A类（中场节拍器）**：前场串联、致命一传。缺阵 → 进攻瘫痪，影响系数 ×2.0
- **B类（后场出球中卫/拖后后腰）**：后场疏导。缺阵 → 后场出球瘫痪，面对高压逼抢极易送礼，影响系数 ×2.0

**离队惩罚机制**（永久离队，非临时伤缺）：

| 离队类型 | 惩罚系数 | 说明 |
| :--- | :--- | :--- |
| 头号射手永久离队 | 额外 -20% | 体系彻底重塑 |
| 组织核心永久离队 | 额外 -20% | 战术体系核心缺失 |
| 普通主力永久离队 | 额外 -10% | 有替代者但实力下降 |
| 临时伤缺 | 按原有等级执行 | 不叠加离队惩罚 |

## 红线3：虚热 vs 实热必须分辨（战意系数）

| 战意场景 | 系数调整 | 案例 |
| :--- | :--- | :--- |
| 保级队主场 | 实力+30% | 巴西国际（保级）vs 弗拉门戈（争冠） |
| 杯赛次回合首回合领先≥3球 | 领先方-30%，落后方+30% | 波兹南4-1领先次回合0-3被翻 |
| 无欲无求 vs 必须抢分 | 必须抢分方+20% | 雅罗保级主场改写历史交锋 |
| 一周双赛/欧战消耗 | 防守稳定性-25%，进攻火力-10% | 济州SK 120分钟加时后防守崩盘3-3 |

**矛盾信号权重排序**：

| 优先级 | 信号类型 | 权重指令 |
| :--- | :--- | :--- |
| 🥇第一优先 | ≥3名主力同时回归 | 直接抵消"体能消耗"负面影响 |
| 🥈第二优先 | 尊严惨败反弹（红线15） | 进攻爆发系数×1.5~2.0 |
| 🥉第三优先 | 对手是否为🔴重度残阵 | 若对手残阵，强队无需全场高强度跑动 |
| 4️⃣第四优先 | 一周双赛/欧战消耗 | 优先扣防守稳定性(-25%)，其次扣进攻(-10%) |

## 红线4："看起来最稳的"往往最不稳
当一场比赛被所有人视为"稳胆"（支持率>75%）时，必须反问："什么情况下会翻车？"找不出合理翻车理由 = 分析还不够深。

## 红线5：双选的本质是覆盖不确定性（容错层级）

| 冷门层级 | 定义 | 双选策略 |
| :--- | :--- | :--- |
| 小冷 | 强队变平局 | 主串关双选：胜/平 |
| 中冷 | 强队输球 | 主串关双选：负/让负 或 负/平 |
| 大冷 | 强队惨败（输2球以上） | 单独防冷小串，不在主串关中双选 |

**防线核心缺阵的竞彩映射**：后防领袖/B类组织核心缺阵 → 必须双选"让负/让平"。

## 红线6：惨败反弹定律（V3.0修正：区分惨败性质）

| 惨败类型 | 判定标准 | 反弹系数 | 案例 |
| :--- | :--- | :--- | :--- |
| 尊严惨败 | 输给低级别球队/死敌/被绝杀逆转/德比惨案 | 进攻爆发×1.5~2.0，总进球预期大幅上调 | 蔚山0-1输K3蔚山市民 → 次战3-1安养 |
| 技战术惨败 | 输给明显更强的对手，场面被碾压 | 按原规则执行（实力+30%） | 罗森博格0-5曼联 → 次战4-0腓特烈 |
| 偶然惨败 | 红牌/点球等偶然因素导致的大比分 | 反弹系数减半 | — |

**操作指令**：识别到"尊严惨败" → 主动上调该队进球预期+1球，大小球盘口自动看大；若尊严惨败方同时有在阵核心健康 → 叠加×1.5系数。

## 红线7：两回合杯赛"首回合大比分领先"必须反向思考
一方首回合净胜≥3球 → 次回合该方战意大幅下降，落后方战意急剧上升。

## 红线8：保级队主场战意系数
保级区球队主场作战 → 战意自动提升1档，拿分概率比正常水平高20-30%。

## 红线9：非运动战进球概率因子
一方进攻端严重缺人时，其进球方式更依赖定位球、点球、对手乌龙等非运动战手段。

## 红线10：残阵防守韧性因子

| 球队风格 | 缺阵类型 | 韧性评估 |
| :--- | :--- | :--- |
| 摆大巴型（控球率<45%） | 缺普通中卫/边卫 | 韧性极高，体系>个人 |
| 控球型（控球率>55%） | 缺后场出球核心（B类） | 韧性极低，极易崩盘 |
| 任意风格 | 缺门将（一门） | 韧性急剧下降 |

## 红线11：主力集中回归的叠加效应
一方有≥3名主力同时回归 → 整体实力提升不是简单相加，而是指数级上升。

## 红线12：惨败后次战，补时阶段专注度下降
一方上一场联赛净负3球以上 → 次战领先状态下补时注意力不集中，补时丢球概率显著上升。

## 红线13：跨级别杯赛首回合陷阱
五大联赛/巴甲豪门 vs 低级别球队的杯赛首回合 → 优先考虑1球小胜或平局，穿盘需格外谨慎。

## 红线14：博冷场次隔离原则
博冷方向不得放入主串关单选，必须单独小串或明确标红警告。

## 红线15：尊严惨败系数
一支球队上一场经历"尊严惨败"（定义见红线6）后，下一场进攻爆发力异常升高（情绪驱动的物理定律）。

**强制操作**：

| 场景 | 操作指令 |
| :--- | :--- |
| 尊严惨败方 vs 任何对手 | 总进球预期上调+1球 |
| 尊严惨败方 vs 防守残阵/体能崩盘对手 | 总进球预期上调+1.5球，优先考虑4球以上大球 |
| 尊严惨败方同时有≥2名在阵进攻核心 | 叠加×1.5系数 |

案例：蔚山现代周中韩国杯0-1输K3蔚山市民（尊严惨败）→ 次战K联赛对安养FC，旧框架小球（1/2球），V3.0修正为大球，实际3-1。

## 红线16：体能权重再分配
体能消耗首先摧毁**防守稳定性**，而非进攻火力。

| 体能消耗程度 | 防守稳定性扣减 | 进攻火力扣减 | 案例 |
| :--- | :--- | :--- | :--- |
| 周中常规联赛（正常消耗） | -10% | -5% | — |
| 周中杯赛（全力出战） | -15% | -10% | 常规杯赛消耗 |
| 周中杯赛120分钟+点球 | -25% | -10% | 济州SK 120分钟加时后防线3-3崩盘 |
| 连续3周一周双赛 | -30% | -15% | 长期积累疲劳 |

**操作指令**：识别到"120分钟加时" → 大小球盘口自动看大+0.5球；防守崩盘预期 → 对手预期进球数上调，即使对手进攻端有残阵。

**V3.2 补充**：欧战资格赛刚结束+主帅亲承赛程密集 → 按"周中杯赛级"处理（防守-15%起），并叠加"欧战留力轮换"预期（战意削弱）。

## 红线17：极端烂防豁免条款
对手防守达到"历史级烂防"阈值时，己方"进攻残阵"扣减权重自动降权——烂防会自动送礼、漏人、送点。

| 烂防等级 | 判定标准 | 豁免规则 |
| :--- | :--- | :--- |
| 🔴历史级烂防 | 场均失球>2.0球（联赛垫底水平） | 对手"进攻残阵"扣减降权50% |
| 🟡严重烂防 | 场均失球1.6~2.0球 | 对手"进攻残阵"扣减降权25% |
| 🟢普通烂防 | 场均失球<1.6球 | 不触发豁免，正常执行 |

**追加信号（烂防等级自动升1级）**：客场连续10场以上丢球；防线核心+门将同时缺阵；近5轮场均失球>2.5球（直接触发🔴）。

**V3.2 补充**：近10场与近6场场均失球口径不一致时，**取更高等级**（002案例：哈尔姆斯塔德近10场失21球=2.1/场 → 🔴历史级，即使近6场为2.0/场 🟡边界）。

**操作指令**：对手触发🔴 → 即使本方进攻端残阵，仍可预期本方进球≥1.5球。案例：大田市民（4攻击手伤停）vs 光州FC（场均失2.25球）→ 大田仍进2球。

## 红线18：在阵核心兴奋度加权
尊严惨败反弹（红线15）+ 在阵进攻核心≥2人健康 → 进攻爆发力相乘而非相加。

> **预期进球 = 正常预期进球 × 尊严系数（1.5~2.0）× 在阵核心系数（1.0 + 核心人数×0.15）**

| 在阵核心人数 | 系数 |
| :--- | :--- |
| 0人 | 1.0（尊严惨败也无从爆发） |
| 1人 | 1.15 |
| ≥2人 | 1.3 |

案例：蔚山尊严惨败（×1.5）+ 亚戈+李东炅双核心在阵（×1.3）→ 预期进球大幅上调，实际3-1。

## 红线19：实力差距修正系数
双方排名差距≥8位时，所有体能消耗、防守残阵扣减权重自动减半——实力鸿沟压倒一切修正项。

| 排名差距 | 体能消耗扣减 | 防守残阵扣减 | 说明 |
| :--- | :--- | :--- | :--- |
| ≥8位（强弱悬殊） | -7.5%（原-15%） | -7.5%（原-15%） | 实力差距压倒修正项 |
| 4-7位（中等差距） | -12% | -12% | 适当下调 |
| ≤3位（实力接近） | -15%（原规则） | -15%（原规则） | 实力接近时，残阵/体能成决定性因素 |

案例：奥勒松（第13）vs 特罗姆瑟（第3）差10位 → 特罗姆瑟体能扣减从-15%降至-7.5%，实际2-6屠杀；布兰（第9）vs 罗森博格（第10）差1位 → 不触发，按原规则。

## 红线20：历史底蕴恢复条款
近10次交手胜率≥60%时，即使当前阵容有残阵，历史权重恢复至70%——心理压制和战术克制不会因几场伤病消失。

| 近10次交手胜率 | 历史权重 | 说明 |
| :--- | :--- | :--- |
| ≥60%（绝对优势） | 恢复至70% | 心理压制+战术克制 |
| 40-59%（均势） | 50% | 参考但不主导 |
| <40%（劣势） | 30% | 历史参考价值有限 |

**例外**：双方阵容发生根本性变化（头号射手/组织核心永久离队、换帅后战术体系彻底改变）→ 历史权重自动降至30%，以当前实力为准。

案例：布兰近10次对罗森博格6胜3平1负（胜率60%）→ 触发，防线残阵仍靠历史底蕴+主场3-2赢球。

## 红线21：主场"不败假象"识别

| 识别信号 | 判定 | 操作 |
| :--- | :--- | :--- |
| 近6主场1胜5平 | ⚠️假象嫌疑 | 重点检查5场平局的对手 |
| 5场平局中≥3场为0-0或1-1 | 🔴进攻乏力 | 主场不败因对手弱，而非自身强 |
| 平局对手排名全部低于己方 | 🔴含金量低 | 遇到强队时防守随时可能崩盘 |

案例：奥勒松近6主场1胜5平，平局对手均中下游 → 遇特罗姆瑟（第3）防线被打穿2-6。

## 红线22：大比分屠杀预警
同时满足以下**≥3项**时，必须将强队大胜（赢2球以上）纳入首选，不能保守选"让负/胜平"：

| 序号 | 触发条件 | 判定标准 |
| :--- | :--- | :--- |
| ① | 排名差距 | ≥8位 |
| ② | 弱队"不败"含金量低 | 近6主场平局≥3场且对手均为弱队 |
| ③ | 强队攻击线完整 | 强队进攻核心全部在阵 |
| ④ | 弱队防守端有伤停 | 弱队防线有主力缺阵 |
| ⑤ | 强队近期进攻效率高 | 近3轮场均进球≥1.5球 |

满足≥3项 → 优先考虑强队让球方向（让胜/让平）。案例：奥勒松vs特罗姆瑟 5项全满足 → 实际2-6。

## 红线23：进攻残阵兜底条款
弱队进攻端严重缺人时，即使强队体能消耗大、防守有残阵，弱队也很难利用漏洞——弱队自己进不了球。

| 弱队进攻端状态 | 强队体能消耗扣减 | 说明 |
| :--- | :--- | :--- |
| 头号射手缺阵+组织核心缺阵 | -7.5%（原-15%） | 弱队自己进不了球 |
| 头号射手或组织核心缺阵 | -10% | 进攻端有明显短板 |
| 进攻线完整 | -15%（原规则） | 弱队有能力惩罚强队防守漏洞 |

案例：瓦萨头号射手范杜伊文博登长期缺阵 → 国际图尔库一周双赛体能扣减从-15%降至-7.5%，实际国际图尔库客场1-0赢球。

## 红线24：次回合战意局——落后方主场晋级线（V3.15 新增 · 规则15 补丁/34）
两回合次回合，**落后≤1球 + "赢2球=直接晋级" + 实力差支撑（身价/排名/主客场）三要素全中 → 让胜进主推候选**（萨巴赫4-0/采列2-0/里昂3-0 3/3 全中让胜，我们全给让平）；**无实力支撑 → 翻盘失败小球**（凯拉特0-1/格拉茨0-1）。领先方主场次回合也会出让胜（布拉迪2-0，首回合客场2-1赢）。**次回合局让平是窄格（7次主推让平只中1次14%），让平只在均衡局+双方接近才是主格**；主推让平时防冷位放让胜。

## 红线25："高信心⭐"是危险信号（V3.15 新增 · 规则35）
连续 7 次高信心场翻车：8/3 佐加顿斯、8/5 奥林匹亚科斯、8/6 塞萨洛、8/7 埃斯托里、8/9 维京、8/10 天狼星、8/11 布拉迪——**信心来自数据全/模板熟，翻车全在场景识别错**。标⭐前先过场景分类双查（让球格是否随场景成立、是否锚定单一精确格）；⭐场降级小注/防冷位，主推给"场景清晰+格宽"的场。

## 红线26：格子宽窄随场景变（V3.15 新增 · 规则34 补注）
同样一个结果格，场景不同宽窄不同：**警示局让平 5/13（高频格）vs 次回合局让平 1/7（窄格）**；8/8-8/10 锚定"赢2球"、8/11 锚定"赢1球"同根——先定场景再定格宽窄，禁止先锁格再找理由。

## 红线27：平局率信号优先于模板（V3.15 新增 · 规则24 补丁）
客队客场平局率≥35% / H2H 多平 / 多源提示平局 → 平局对应格（让球方平=让负、受让方平=让胜）优先于警示局模板让平（弗鲁米 H2H 6场5平 → 0-0：晨版让负✅被晚版模板化改坏；江原 0-0✅、奈梅亨 1-1✅ 三连验证）。修订要有新硬信号依据，晨版已对的不改坏。

## 红线28："场次性质"叙事禁压档（V3.16 新增 · 规则19 补丁）
