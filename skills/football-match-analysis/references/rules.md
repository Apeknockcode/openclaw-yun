## 多源交叉验证（规则 1-52 · 完整案例见 references/case-library.md「历史归档」段；此处为压缩版判定逻辑）
> **容量归档（2026-08-18 V3.24）：V3.2~V3.21 历史复盘摘要与 V3.22~V3.23 批次明细已全部移入 case-library，此处规则保留当前生效判定逻辑+一句案例索引。**

1. **关键信号（伤停/残阵/战意/体能）必须 ≥2 独立来源确认**：官方伤停名单+深度赛前文+海外模型，两处一致才采信。
2. **单源信息**：标"待验证"，权重降半，不直接决定方向。
3. **来源冲突优先级**：官方伤停名单 > 深度赛前文 > 海外模型。
4. **排名差≤3位但让球≥1球（盘口偏深）→「盘口深双信号判别」**：主队近6场场均进球≥2 且 客队客场场均失球≥2 → 盘口深=市场强信号（大胜预期），回归让胜、海外模型平局不采信；双方状态/火力接近才采信模型平局 → 让平/让负双选；排名差≤3 但一方传统强队/一方保级升班马 → 排名接近是假象，按实力鸿沟处理。
5. **残阵区分「主力框架完整」与「结构崩盘」**：长期伤号缺阵 ≠ 重度残阵；同位置多人缺阵/核心位置+门将全缺 才算 🔴。
6. **对手防线结构崩盘 → 本方让胜可单选、比分+1**；前置条件=本方状态正常（季前≥2连败/慢热/锋无力 → 降级双选/防平、比分不+1、不得做串关单选胆）。
7. **方向可激进、比分要克制**：方向经多源验证可升单选，比分保持原双选范围，不做大幅上调。
8. **信号齐全必单选，双选=信心不足**。复盘口径：双选命中=「覆盖」不算方向命中，主推单选才算。
9. **外部意见不能推翻框架主判**：海外模型/DeepSeek 只做交叉验证；冲突时回 7步法主线复查（实力差距→防守崩盘→排名质量），不直接改判。
10. **盘口警示信号必须执行**：让球显著浅于实力差/历史交锋 或 明显退盘/降盘 = 市场否定强队 → 走受让方不败方向（让胜/让平），不得因名气/身价/交锋强推；识别后最终判定必须体现（退盘/降盘单独出现也是强信号）。
11. **大小球看双方防线真实状态**：判小不能基于"单方防守稳/对方进攻残"（个人缺阵≠体系崩）；单方防守数据好不能锁死小球（状态火热对手可打穿任何"数据防线"）；双方防线有洞/一方刚被屠杀 → 大球；判平局时防线都有问题 → 平局比分放开 2-2/3-3。
12. **比分预测按比赛类型分档**：杯赛次回合+浅盘 → 小比分可信可精确；互爆/状态差 → 范围放大给大比分备选；方向对≠比分对，串关不押比分。**三锁一放（V3.18）**：锁档位（比分之和=进球档位）、锁方向（先定让胜/让平/让负再格内选）、锁BTTS（8月开局期 81% 双方进球，优先 1-1/2-1/1-2/2-2）；放大球局（档位≥4球只给范围）。高频锚点：让平→2-1/1-0、平局→1-1（均衡）/2-2（有火力）、让负→1-1/2-2、让胜→2-0。主推+防冷=两个剧本翻倍；放弃比分串关。
13. **让球方防线残阵（结构崩盘）+ 对手反击完整 → 客队进球预期≥1.5-2、总进球下限 2-3 球**；状态信号不能压倒结构崩盘信号。
14. **盘口口径统一标注**：主队(-1)=让1球、主队(+1)=受让1球；判定前让球演算，输出【竞彩映射】附演算行。
15. **杯赛次回合落后方主场战意盲区**：首回合落后方（尤其主场）必须赢，战意可压倒状态数据与浅盘 → 让负判定强制降级双选；"轮换留力"≠"客队稳守"。**V3.15 晋级线重估**：落后≤1球 + 赢2球=直接晋级 + 实力差支撑三要素全中 → 让胜进主推候选（至少让平+防冷让胜）；无实力支撑 → 翻盘失败小球。**V3.17 补注**：落后方**客场**同样战意驱动（必赢→进攻放开→大球），不分主客场（007 塞萨洛 3-2 五球）。
16. **市场过热反向**：升盘 + 支持率共识≥80% 同时出现 → 方向不得单选，让胜降级双选（让胜/让平）或防冷让平；热度偏差>20% 同规则处理。
17. **对手防线结构崩盘 → 总进球档位直接 4+**（本方状态正常为前提，规则6）。
18. **状态面 > 传闻面/叙事面**：硬状态数据（近6场攻防/热身/末段走势/主客场）优先；传闻需官方确认才进判定且不得压过状态数据；状态火热主队不因场外传闻降权；"换帅"官方确认才记风险栏，不进主判。
19. **联赛首轮/揭幕战不预设保守**：按双方防线真实状态正常判定，"揭幕战/新帅磨合/客队求稳"叙事不得压档。**V3.14**：首轮+双方无近况数据 → 进球回基线 2-3 球，禁机械压 0-1（无数据≠弱攻）。**V3.16**："场次性质"（决赛/单场淘汰/决胜局）同样禁压档——任何场次性质都不是压档依据，按攻防实力正常判定。
20. **互爆识别**（双方防线各有漏洞+至少一方状态火热）→ 档位 3-4+/4+、大2.5起、比分放大（3-2/2-3/4-3 级备选）；结果常落"一方1球小胜"（双让平）→ 方向不确定时双选覆盖让平格。
21. **强队客场"求稳"信号慎用**：媒体报道≠进球少，实力差局强队落后会放开反扑；不得作为压档依据。
22. **深盘警示局**（竞彩-1 vs 亚盘 0.25~0.5 区间）→ ①方向：主推让平/让负双选（让球方1球小胜或不胜）——累计 17 场让平8/让负6/让胜3（让平+让负=82%）；**市场让负赔率最热≠实际高频**；让胜（赢2球）排除；**亚盘≤0 不算警示局（规则28）**；②进球压档分型：双方弱攻/铁桶 → 压 1-2球/小2.5（本月最强模块）；让球方有火力/状态火热 → 不压档回 2-3 球；③例外：互爆识别/大球H2H 直接判大。**V3.12 模板化不让名气破例**（015 特温特教训，累计 19 场 15/19≈79%）。**V3.14**：主推让平+防冷让负=等效双选，复盘记「防冷覆盖」不算判断错。**V3.15**：次回合落后方主场战意局 → 模板降权、走规则15/34（萨巴赫/采列让平全挂）。**V3.28 补注（011 贝蒂斯 1-0）**：**警示局+让平主格 → 进球压 1-2球/小**（011 判 3球/大2.5 → 1-0 判3实1 全错；让平主格=赢1球剧本，进球不该判 3，除非双方火力有硬证据）。
23. **主推单档两极判定**：进球分布天然两极，先问"1球局还是4球局"；只有"双方攻防均衡+都有明确进球能力"才主推 3 球（3球是临界不是安全默认）；深盘警示局有火力方回 2-3 球（规则22②）。
24. **平局高频信号必须进主推格**:1多源提示平局概率高 2客队客场平局率≥35% 3双方状态均差 → 平局对应让球格进主推(让球方平=让负、受让方平=让胜);**识别了就要落进判定,风险栏≠判定**(金泉 0-0 让胜单选✅先例)。**V3.14 鸿沟局不压**:实力鸿沟只能降概率不能清零,平局格至少留防冷位(布鲁马波 37.5% 被压掉→2-2)。**V3.15**:平局率信号局优先于警示局模板(弗鲁米 H2H 6场5平→0-0;江原/奈梅亨三连验证)。**V3.23 三件套**:方向让球方不胜 + 平局比分(1-1/0-0)进首选 + 进球锁 2球/小2.5,**大小球升盘不覆盖平局率信号**(升盘=热度不是攻防证据;累计 8 次验证 0 失误=本月最稳模块)。**V3.25 弱触发补丁（002 AEK 0-0）**：C2 平局剧本**只要触发（含「首回合+客队韧性」弱触发）→ 主推=让球方不胜侧（平局对应格），让平（恰好赢1球）只做防冷**——002 识别平局剧本却主推「AEK 恰好赢1球」让平 → 主推挂、防冷（AEK 不胜）兜。**V3.26 降级补丁（003 波特诺 0-1 帕尔梅）**：**C2 弱触发（首回合平+主队 H2H 不败，无客队客场平局率硬数据）→ 不进主推，只降信心/小注/防冷位**；实力鸿沟（巴甲豪门帕尔梅 vs 巴拉圭波特诺，规则6）优先于弱触发平局剧本；主串腿禁选弱触发场。区分：**C2 强触发（客队客场平局率≥35% 硬数据/多源提示平局）才可主推让球方不胜侧**——V3.25「弱触发也落格」只适用强触发（002 AEK 方向对是强触发后置），003 是弱触发直接主推受让方不败 → 帕尔梅 0-1 翻车。
25. **盘口信号 > 欧赔概率**：退盘/降盘+深盘警示 → 方向坚定走受让方不败，禁止因欧赔隐含概率高切不让球"胜"（退盘=市场否定让球方）。**V3.17 执行补丁**：退盘+让球方状态差 → 主推受让方+1 让胜（不败），不得主推让球方让平（006 流浪者识别退盘却让平→1-1）。**V3.34 补注（用户金句固化）**：**机构升水/涨水 ≠ 预测胜负**——水位变动主要是注码平衡/赔付管理（哪边买多压哪边水位），不代表机构看衰某队；**只有让球线（盘口）移动才是市场态度信号**（退盘/降盘=市场否定让球方），水位单独变动不作方向依据（规则53 同源：市场赔率只作热度参考不作方向依据）。
26. **近况数据时效校验**：“进攻荒/状态差/连败”必须核对最近 1-2 轮是否已破（500.com shuju 实时源）；过时单源数据超 2 轮不采信；**方向靠盘口、进球数靠最近 1-2 轮真实状态**。**V3.26 补丁——热身赛数据降权（002 马竞 2-0）**：季前热身大比分（马竞末段 1-5 惨败）**不构成正式比赛防线崩盘/状态证据**（热身赛强度/轮换≠正式比赛，马竞正式 2-0 零封）——大小球判大/防线崩盘推断需正式比赛攻防数据，热身赛数据降权处理。
27. **真深盘（亚盘≥竞彩）"让球方赢2球"是窄格**：主推让平/让负双选，让胜仅当"对手防线结构崩盘🔴+本方火力正常"才单押；"赢2球"窄格禁做串关腿/胆（8/9 六场让胜仅 1/6）。**V3.14 豁免收紧**：排名差/实力鸿沟/对手近6场0胜/状态差都不是豁免（天狼星 2-2，累计让胜 1/7≈14%）。**V3.16 超级大热也不豁免**：帕尔梅 1.22 也只 1-1（累计 2/9≈22%）——热度/名气/大热盘都不豁免让胜窄格。
28. **亚盘≤0（平手/受让）= 势均力敌信号，不是深盘警示**：进球不压档；平手盘+双方有火力 = 互爆大球（规则20 优先），不锁小；方向让平/让负双选或受让方不败，不是让胜主推；比分档位放开（对攻剧本）。
29. **-2 深盘用受让方视角**：主推"受让方+2 让胜/让平"（宽格），禁"恰好赢2球"窄格；火力凶≠深盘兑现（宽格累计 5/5）。**V3.23 补丁——超级大热深盘判定放宽**：欧赔≤1.25 豪门级大热（vs 保级/中下游，排名差≥8 或级别差，**主客场不限**）+ 深盘（亚盘≥-1.5/竞彩-2）→ 受让方宽格让胜格（让球方赢≤1球）**禁主推、禁串关腿**，主推跟随盘口侧（受让方+2 让平）或跳过，进球 3-4球/大2.5 起步禁压小；**深盘宽格只保护「让球方状态存疑」**（轮换/核心伤停/即时连败客场虫）——H2H 上季小样本/首轮平局不是状态存疑证据（盘口比 H2H 诚实，规则31 反向）；005 卡萨皮亚 0-7 本菲卡 1.21 / 021 利雅胜利 1.12 同型二连——**先过超级大热判定再决定是否用宽格**。
30. **主推玩法二选一（让球 vs 不让球）**：每场【竞彩映射】只给**一个 🎯 最终主推**，非主推口径只作换算展示+一句"为什么不主推"。选择标准：①方向落在让球特有格（赢1球/赢2球/受让区间）→ 让球主推（深盘警示/真深盘/-2深盘、判断"赢1球或不胜"的场次）；②方向是宽泛不败类 → 不让球主推更精准（强弱分明无盘口反向+赢球数判不清→不让球胜；"主队不败"→胜/平双选；"受让方不败"→平/负双选）；③规则25 无退盘/降盘/深盘警示 → 可切不让球胜。**禁止主推不让球**：深盘警示局/真深盘/-2深盘（不让球换算=胜平负全包零区分度）、退盘局。**双口径换算**：让胜/让平→不让球胜（宽格）、让负→不让球平/负双选。V3.13：主推必须单选项（规则33）。

31. **警示局模板化执行，不让名气破例**：警示局+强队让球 = 市场已否定（盘口比名气诚实，第三次实证：里昂/特温特），名气/身价/实力差/H2H 不得翻盘盘口信号；不得因"强队"切不让球胜。
32. **串关全宽格**：主串腿 100% 宽格（受让方不败/让球方最多赢N球（平/输也算）/让平让负双选），窄格腿（赢2球/恰好2球）零容忍；博冷隔离单独小串不混主串，博冷腿也用宽格表达；主串场次必须"值得买"级。**V3.24 升级（C7）**：主串腿 = **方向主推级信心 + 宽格表达，缺一不可**——宽格只保护"方向对但赢球数差一点"，方向全反救不了（002 海牙/011 阿森纳/005 本菲卡三次实证，全宽格主串两次中断+失败全死在方向错腿）。**V3.25 补注——宽格必须真宽（001 博冷腿教训）**：人话写「最多赢N球」必须对应真宽格（让平∪让负 / 让胜∪让平 **两格都买**），只挂单注窄格（如让平单注「恰好赢1球」）不算宽格——001 博冷腿写「门多萨最多赢1球」实为让平单注 5.65，1-1 让负不中（真宽格则中）；**博冷腿与主串腿同标准，写宽格人话必须真买两格**。**V3.27 补注——一腿双杀禁所有串（8/20 004 阿拉木图）**：004 同时进主串 3串1 和 8串1 = **同一个方向错腿杀了当天全部串**（3串1 挂 + 8串1 七腿对仍全灭）——**方向信心不过硬（只有单边叙事、无盘口信号支撑）的场次，主串和长串都不许进，一个串都不留**；多串并存时先逐个核腿，可疑腿在所有串里同步剔除。**V3.29 补注——多串腿三门槛（8/23 用户反馈「多串要提高一下」）**：多串/长串腿数封顶 5 条；在「方向主推级信心+宽格」之上再加：①非对抗市场（-1盘受让方不败/+1盘强队不胜/平手盘受让方不败三类直接剔除——8/22 023 那不勒斯不胜 0-2 三批全灭的死腿全是此类）②最稳模块优先（规则24 平局率/客队低水+实质优势/警示局客队低水让负/深盘+主队低水赢球）③死腿防呆五查（规则59/60/58/49/61 任一触发即剔除）；凑不满 5 条就少给，禁硬凑；想提高存活率默认给容错结构（5串10/4串11），用户明确搏高赔才单式。
