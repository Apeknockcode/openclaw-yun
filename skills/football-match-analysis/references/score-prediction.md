## 比分预测规则
0. **V3.45 输出收缩（9/7 用户拍板：进球单档与精确比分长期低命中=输出成本高）**：①总进球输出=**方向（大/小）+ 区间档**（2-3/3-4/1-2），单档只在强证据给且只作混合过关区间腿/高配单输入，**不作主推依据**（判档连续三批崩：9/6 判2 命中 4/15、判小 2/9）；②比分只在**有剧本证据的场**给 2-3 个（平局体质/克星/强强慢热/121 红线场），其余场只给方向族（主胜=1-0/2-1/2-0）；③比分仍不单关、只走 2串1 复式（每场2选）/3串1（8注）分层「必买/可选/搏冷」。
1. **每场最多2个比分**：1个"最可能"，1个"防冷"。
2. **比分与大小球盘口对齐**：大小球盘口2.5球 → 比分总进球不超过3球。
3. **比分串关最多2场**。
4. **双向伤停约束**：双方进攻核心都有缺阵时，检查双方防守端是否也有致命漏洞。若有防守崩盘信号（红线15/16/17），小球判定失效，优先考虑大球比分。
5. **非运动战进球提醒**：一方进攻端严重缺人时，其进球更可能来自定位球、点球或乌龙。
6. **主力集中回归提醒**：一方有≥3名主力同时回归时，比分预测应更大胆。
7. **极端反击阈值**：同时满足≥3项条件时，必须将弱队净胜2球以上的比分纳入防冷首选。
8. **跨级别杯赛首回合比分约束**：巴甲豪门vs低级别首回合，默认只给1-0、0-0、1-1。
9. **实力差距主导比分区间**：先看实力差距，再叠加修正项。

| 实力差距 | 强队预期进球 | 弱队预期进球 | 优先比分 |
| :--- | :--- | :--- | :--- |
| 悬殊（排名差≥8位）+ 强队攻击线完整 | ≥2.5球 | ≤0.5球 | 2-0、3-0、3-1 |
| 悬殊（排名差≥8位）+ 强队攻击线有缺 | ≥1.5球 | ≤1.0球 | 1-0、2-1 |
| 接近（排名差≤3位）+ 防守残阵 | ≥1.5球 | ≥1.5球 | 1-1、2-2 |
| 接近（排名差≤3位）+ 进攻残阵 | ≤1.0球 | ≤1.0球 | 0-0、1-0 |

10. **防守加法优先于进攻减法**：必须先计算"对手防守会不会崩"，再计算"己方进攻残不残"。

| 防守崩盘信号触发 | 操作 |
| :--- | :--- |
| 尊严惨败触发（红线15） | 进球预期+1球 |
| 体能崩盘触发（红线16） | 对手进球预期+0.5~1球 |
| 烂防豁免触发（红线17） | 进攻残阵扣减降权50% |
| ≥2条信号叠加 | 总进球预期直接上调+2球，优先考虑大球比分 |

案例：001蔚山（尊严惨败触发）× 济州SK（体能崩盘触发）= 两场均为大球，实际3-1和3-3。

11. **比分按比赛类型分档（V3.4 规则12 · V3.15 确认）**：杯赛次回合+浅盘+首回合小分差 → 小比分双选可信、比分首选可精确（001 里莫 0-1）；矛盾战/双方防线互爆 → 比分范围放大、给大比分备选（3-2/2-3/4-3）；**战意局（次回合翻盘）比分两极——翻盘成功 3-4球（萨巴赫4-0/里昂3-0）、翻盘失败 0-1球（凯拉特0-1/格拉茨0-1），不锁单一比分（V3.15）**。

## 比分命中提升策略（V3.18 新增 · 第12条，8/3-8/14 共54场复盘统计）

**现状基线（严格口径）**：主推精确比分 9/54 ≈ 17%，加防冷 ~26%——四要素里最弱项；命中的比分高度集中 1-1/2-1/0-1/1-0（8/9 六中全是小比分局：007 1-1/010 0-1/013 1-0/014 0-1/019 0-1/025 1-1），**大球局（4球+）精确比分从未命中**（8/7 0/8、8/11 0/10、8/14 0/16）——进球越少比分越可猜，结构性规律不是运气。

**三锁一放（每次预测比分前过一遍）**：
1. **锁档位**：比分是进球档位的具体化——档位错比分必错（8/14 全灭根因=进球全低估却按 1-2 球猜比分）；先过规则36/37/38/40 把总进球判准，比分之和必须=档位。
2. **锁方向**：先定让胜/让平/让负，再在对应格内选比分，禁止跨格猜（判断让平 → 候选只有 1-0/2-1/3-2，配合火力选 2-1）。
3. **锁BTTS（双方进球）**：8 月开局期 13/16 场（81%）双方进球——优先选双方都有进球的组合（1-1/2-1/1-2/2-2/3-1），单方零封（1-0/2-0/3-0）必须有"弱攻+铁桶"硬证据才给。
4. **放大球局**：档位 ≥4 球时比分组合爆炸，精确猜=负期望——只给范围（2-2/3-1/3-2 区间）或标"比分娱乐不重仓"。

**各让球格内高频锚点（实证）**：
| 让球结果 | 最高频比分 | 次选 | 说明 |
| :--- | :--- | :--- | :--- |
| 让平（-1方赢1球） | **2-1** | 1-0 | 8/13 002 ✅、8/14 005 均 2-1；弱攻局才 1-0 |
| 平局 | **1-1**（均衡） | **2-2**（有火力） | 8/14 四场 2-2 全为 -1 热门被追平 |
| 让负（-1方不胜） | **1-1 / 2-2** | 0-1/1-2 | 热门先进后被扳平/反超是常见剧本 |
| 让胜（-1方赢2+） | **2-0** | 3-0/3-1 | 净胜恰好2球是让胜最密集格 |

**实操纪律**：①主推+防冷=两个剧本（主推给"方向对时最可能"，防冷给"另一常见剧本"如 1-1），命中率约翻倍（8/13 防冷 3/10 > 主推 2/10）；②低比分局（档位≤2球：深盘警示/弱攻/杯赛浅盘）才把比分当正经玩法，大球日/数据缺失日只娱乐不重仓；③**放弃比分串关**（17%×17%≈3%），比分只玩单关小注。

## 双向伤停矩阵（框架第4节）
双方进攻核心都有缺阵时的处理：
- 核心动作：检查双方**防守端**是否也有致命漏洞。
- 有防守崩盘信号（红线15/16/17）→ **小球判定失效**，优先大球比分。
- 无防守崩盘信号 → 正常执行小球/小比分。
- 残阵≠必崩盘：摆大巴型缺普通后卫韧性极高（红线10）；**体能崩盘=防守必崩**（红线16）。

## 让球/不让球双口径映射（V3.11 新增 · 规则30 · 修订：唯一主推）
每场【竞彩映射】只给**一个 🎯 最终主推**（玩法+选项），由分析者按"哪个玩法最能表达方向判断 + 赔率价值"决定，**不给并列选项让用户自己选**；双口径都列出，非主推口径只作换算展示并给一句"为什么不主推"。

### 不让球主推场景
| 场景 | 🎯 主推 | 说明 |
| :--- | :--- | :--- |
| ① 强弱分明（排名差≥8位/实力鸿沟）+ 无盘口反向信号 + "赢1球vs赢2球"判不清 | **不让球胜**（宽格） | 适合串关腿；赔率<1.4 标注"仅串关腿，单关无价值" |
| ② 方向判断是宽泛不败类："主队不败" | **不让球胜/平 双选** | 排除客胜，比让球双选更精准 |
| ②' "受让方不败" | **不让球平/负 双选** | 排除大胜 |
| ③ 规则25 场景：无退盘/降盘/深盘警示 | 可切**不让球胜** | 001 樱花✅先例 |

### 让球主推场景（不让球只标"仅参考"）
- **深盘警示局 / 真深盘 / -2深盘**：让球双选（赢1球∪不胜）换算到不让球口径 = 胜平负**全包、零区分度**——不让球在这类局没有信息量，仍主推让球。
- **势均力敌局判断"赢1球或不胜"**：让球让平/让负双选主推（不让球表达不了"赢1球"这个格）。
- **一切"赢几个球"是关键判断的场次**。
- **退盘/降盘局**：规则25 禁止切不让球胜。

### 双口径换算
| 让球口径 | 不让球口径 |
| :--- | :--- |
| 让胜 / 让平（赢≥1球） | **不让球胜**（宽格） |
| 让负（不胜） | 不让球**平/负 双选** |

### 输出格式
```
【竞彩映射】🎯 主推（唯一，照买）：玩法 + 选项（演算行）
- 让球：对应选项 + 让球演算行（如 2-1 (-1) → 1-1 让平）——主推或"仅参考"
- 不让球：胜/平/负/双选 + 一句（主推理由 或 "仅参考：此局不让球=全包无区分度 / 规则25禁止"）
【操作】值得买 / 小注观望 / 跳过
```

## 总进球数定档（V3.5 新增 · 主推单档严格口径）
方向判完后把进球预期收敛成**具体总进球数**（竞彩"总进球"玩法口径：0/1/2/3/4/5/6/7+），与【比分】【大小球】三联动。

### 五步法
1. **算基线**：基线总进球 ≈ (A近6场均进球 + B近6场均失球 + B近6场均进球 + A近6场均失球) ÷ 2；数据缺失按 2.5 球保守处理。
2. **套修正**（只叠加已触发项）：

| 修正项 | 幅度 | 来源 |
| :--- | :--- | :--- |
| 尊严惨败 | +1球（德比惨败+1.5） | 红线15 |
| 120分钟加时/体能崩盘 | +0.5~1球 | 红线16 |
| 🔴历史级烂防 | 对方进球上调至≥1.5 | 红线17 |
| 对手防线结构崩盘 | +1球（**本方状态红线时取消**） | 规则6 |
| **让球方防线崩盘（V3.6）** | **客队进球+1.5～2球（状态红线不取消）** | **规则13，001教训** |
| 防线近场被屠杀（单场丢3+） | 对手进球+1 | 规则11 |
| 屠杀预警≥3项 | 强队进球≥2球 | 红线22 |
| 杯赛跨级首回合 | 总进球压至≤2球 | 红线13 |
| 慢热/状态差 | 本方进球-0.5~1球 | 规则6补丁 |
| 弱队进攻残阵 | 总进球压档（屠杀预期打折） | 红线23 |
| 双残阵且无防守崩盘信号 | 压至0-1球 | 双向伤停矩阵 |
| 状态火热方（末段/热身场均≥2球） | 本方进球+0.5~1球 | 规则18（V3.7） |
| 互爆识别（双方防线各有漏洞+一方状态火热） | 总修正+1~2球、直接4+档 | 规则20（V3.7） |

| 次回合战意局 | 翻盘成功=3-4球、失败=0-1球，给区间不锁单档 | 规则15补丁/34（V3.15） |
| 决赛/单场淘汰/首轮/揭幕 | 不预设保守：进球数按双方攻防实力正常判定，禁"决赛谨慎"压档 | 规则19 补丁（V3.16） |
| 两回合首回合+客队客场韧性 | 平局剧本进防冷位（南美解放者杯主客差异大） | 规则27 补注（V3.16） |
| 次回合局（尤其资格赛低级别联赛） | 基线 2-3 球起：落后必攻（主客都是）+领先强队反击+防线差 → 3-4球/大2.5；禁"领先方守成/首回合均衡"压档 | 规则36（V3.17） |
| 主推让负（让球方赢≥2球剧本） | 3-4球/大2.5（对手有火力/落后必攻时）；比分备选含 4球+时禁给 2球/小 | 规则37（V3.17） |
| 平手盘（亚盘≤0）+主队主场场均≥1.5 | 至少 2-3 球，禁压 1 球（仅双方场均<0.8 弱攻型压 1-2 球） | 规则38（V3.17） |

| 让平格场景绑定 | 无亚盘确认禁止按警示局模板主推让平；数据缺失场降信心/跳过（-1盘无场景证据时让负是高频格） | 规则39（V3.18） |

**多信号叠加封顶：总修正不超过+2.5球**（防极端叠加失真）。

⚠️ **V3.6 新增**：让球方防线核心+门将同时缺阵时，客队进球修正强制生效（+1.5～2球），且不受本方状态红线影响——防线崩塌直接导致丢球，状态信号不能压倒结构信号。

3. **定档**（取主区间）：

| 档位 | 适用场景 | 主推单档 | 防冷档 |
| :--- | :--- | :--- | :--- |
| 0-1球 | 死守局（杯赛首回合+双残阵+状态差） | 1球 | 0球 |
| 2球 | 均衡+双方防守稳 | 2球 | 1球 |
| **2-3球** | **主流区间（无大信号默认档）——临界档** | 3球（攻强/防线漏）或 2球（均衡） | 另一档 |
| 3球 | 一方攻强 或 一方防线有漏洞 | 3球 | 2/4球 |
| 3-4球 | 大球信号（尊严惨败/体能崩盘/烂防触发） | 4球 | 3球 |
| 4+球 | 互爆/屠杀预警（红线22） | 5球 | 4/6球 |

**V3.9/V3.15 档位补充**：深盘警示局-弱攻型 → 0-1/2球档（规则22②）；深盘警示局-有火力方 → 3球档；互爆/结构崩盘 → 4+档（规则17/20）；战意局 → 3-4 或 0-1 两极档（V3.15，翻盘成功/失败）。

4. **映射竞彩总进球玩法——主推单档严格口径**：**主推一个具体进球数**（档位内首选数字），防冷补一档。**复盘口径与规则8一致：主推单档命中=进球数命中；防冷档命中=覆盖，不算命中。**禁止用"2/3球"双选当主推糊弄口径。
5. **三联动校验**：①【比分】两个选项的总进球必须落在档位内；②**大小球由主推单档决定：主推≥3球 → 大2.5，主推≤2球 → 小2.5**（2-3球档是临界档，主推3则大、主推2则小，不允许用档位区间含糊跳过）；③矛盾时回查修正项——方向、比分、大小球、进球数不允许互相打架。
