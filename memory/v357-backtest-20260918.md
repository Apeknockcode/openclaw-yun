## 三、回测暴露的问题：153 边界模糊（需收紧）

- 153 原文示例「防线 N 人缺」把 **006（皇社右后卫2人+中卫缺）** 与 **010（马拉加防线4人缺）** 一视同仁 → 若字面执行，006/009（都未点名死法）也可能被剔 → **可能致空仓**（本批若剔到只剩 004）。
- 而 006 本会中、009 本会中 → **153 过严会误杀赢家**。
- **建议收紧措辞**：153 = 「风险栏**明确点名该腿死法**（含「是主要死法」类措辞）**或列出决定性结构性短板（防线核心 ≥3 人缺/门将+中卫同时缺）**」→ 本批仅 008（点名死法）/010（防线 4 人缺）触发；006（3 人缺但未点名死法，且伤者为边卫位）属边界、需临场判断 → 记账不硬剔。
- 若采纳，本批主口径 = 004×006 = **+126.6**。
