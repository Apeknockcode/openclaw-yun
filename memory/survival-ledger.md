## 三、校准口径

- **腿级**：实际存活腿数 / 主串腿数；累计 ×3-5 批后与「预测生存率」比 → 得校准系数 k = 实际/预测。
- **批次级**：主串命中批数 / 总批数。
- **行动**：k<1 → 展示值乘以 k（或直接标 `[未校准]` + 给出历史基准值）；k 稳定后再谈提高赔率。
