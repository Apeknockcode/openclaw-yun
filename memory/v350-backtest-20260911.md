# V3.50 改版差异回测 · 9/10 晚场周四 001-007（晨版 vs 临场版）

**命题**：为什么晨间版（13:16/13:35）与临场版（18:58）结果差这么多？
**一句话结论**：**两版的「方向主推」完全相同（001 罗马/002 科莫/004 斯拉维亚/006 布拉加），差别 100% 在串关结构**——而结构差异由**一条进球腿赔率 0.06 的移动（006 总进球 2-3：1.80→1.74）**级联触发：跌破 ≥1.75 硬宽格门槛 → 晨版结构（科莫×006进球）失去唯一硬宽格腿 → 重建时唯一 ≥1.75 腿=002 进球（2.01）→ 但 002 与最稳方向腿科莫**同场**（禁止同场双腿）→ 被迫换方向腿 → 选到布拉加（=本批唯一死腿）。

## 二、因果链：一条 0.06 的赔率移动如何翻掉整单

```
006 总进球 2-3 腿：1.80（13:16） → 1.74（18:58）   ← 市场更确信"2-3 球"（本该是利多）
        ↓ 跌破 ≥1.75 硬宽格门槛（R128-S 要求每单 ≥1 条 ≥1.75 腿）
晨版结构「科莫主胜(1.59) × 006进球(1.80)」失去唯一硬宽格腿 → 判定不合规 → 必须重建
        ↓ 全批重扫 ≥1.75 腿：001=1.71 / 006=1.74 / 007=1.72 全部跌破；唯一幸存=002 总进球 2-3 = 2.01
        ↓ 002 进球腿与最稳方向腿「科莫主胜」= 同一场（002）→ 同场禁双腿 → 科莫不能用
        ↓ 方向腿只能在 {001 罗马 1.85 / 004 斯拉维亚 2.52 / 006 布拉加 1.43 / 007} 里选
        ↓ R128-S 要求方向腿中高信+无反证 → 只有 罗马(1.85) / 布拉加(1.43) 合格；罗马×002=3.72 越袋(>3.3)
        ↓ 唯一落在 2.6-3.3 袋内且合规 = 布拉加 × 002进球 ≈2.87
```
**这就是"差别这么大"的全部原因**：不是判断变了，是**门槛+同场规则+一个 0.06 的赔率**把唯一正确组合挤掉了。

## 五、教训固化

1. **规则140 得到最强反证级验证**：0.06 的赔率移动 + ≥1.75 机械门槛 = 把一条命中腿换成挂腿；豁免后至少 3 条中奖组合复活。**"进球腿赔率越低=市场越认同=越好"，不能当"无肉"弃用。**
2. **【新观察项】硬宽格腿与最稳方向腿同场冲突**：当"唯一 ≥1.75 腿"落在最稳方向腿（值得买）的同一场 → 该组合被同场禁双腿规则杀死 → 被迫换较弱的另一场方向腿（本批=布拉加）。**处理：宁可改用 科莫单关 + 放弃串，或不违背"值得买优先"去换方向腿**（规则140①已覆盖：改版不得降级值得买级方向腿 → 若坚持，则本批正确动作=保留晨版 or 只出科莫单关）。
3. **临场盘口加深 ≠ 正确信号**（006 全市场加深受一球 → 布拉加输；对比 007 大幅转向+结构性伤停=对）→ 叠加规则62/63 观察项（低水方本批 1/4）；区分点初判=**转向是否有新增结构证据**（007 有主队 4 人伤停含门将；006 只有盘口动）。
4. **两版方向零差异 = 本批损失 100% 来自改版**：巩固规则138/140 的"改版纪律"——改版只允许因**判定信心变化/结构性反证**而改，禁止因赔率小数波动改。
