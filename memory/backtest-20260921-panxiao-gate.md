## 三、结论

1. **改动对症且高收益**：大小方向 42.9% → 66.7%（+23.8pp，纠正 5 场），且**不碰主推、不碰串关**（判小门只作用于总进球方向）。
2. **本批「判小」零增量**：全判大 = 14/21 = 66.7%，与回测结果**完全相同** → 本批 7 场判小没有提供任何正信息，纯失分源（批 Over2.5 = 63.6%，方向本来就该偏大）。
3. **但改动只治标不治本**：主串仍挂（−50），死因是 **011 伯恩茅斯受让方不败**（141 判定层），与判小门无关 → **144/141 的判定层问题仍在观察项**（154 冻结）。
4. **回测暴露的执行细节**：022 是边界样本——若当时真写了 139 双证据且成立，可保留小；回测把它算作「缺门→回大」属**严格口径**，实际命中损失 1 场。→ 说明新规则的价值**不在「判得更准」而在「判错时会留下证据」**。

## 四、注意（诚实标注）

- 本回测是**同一批数据的事后应用**，非前瞻样本；154 要求改动须有前瞻验证 → 本改动记为「**执行层 · 前瞻 0/3**」。
